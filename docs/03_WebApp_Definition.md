# 웹앱 개발 정의서 (Web App Definition)

## 1. 시스템 목적
관리자가 서버에 저장된 전체 사용자의 음성 지문 등록 현황을 관리하고, API 서버의 부하 상태 및 인증 로그를 모니터링하는 관리자 대시보드. 나아가 인증 품질 지표(EER/FAR/FRR)와 판정 임계값을 운영 중 조정할 수 있는 캘리브레이션 콘솔 역할을 겸한다.

## 2. 기술 스택
*   **Frontend Framework:** Next.js (React), TypeScript.
*   **State Management:** React Query (서버 상태 동기화).
*   **UI Component:** TailwindCSS, Shadcn UI.
*   **Backend Integration:** Supabase 및 분석 API 서버와 연동.

## 3. 핵심 기능
*   **대시보드 (Dashboard):** API 호출 횟수, 평균 분석 응답 시간(Latency), 인증 성공/실패율 실시간 시각화.
*   **화자 데이터베이스 (Speaker DB):** 서버에 등록된 사용자의 벡터 지문 상태 확인 — 임베딩 모델명·버전·차원 표기, 모델 교체 시 재등록 필요 사용자 필터링 (보안을 위해 원본 오디오는 분석 후 즉시 서버 메모리에서 파기).
*   **오딧 트레일 (Audit Trail):** 시간대별 API 요청 IP, 대상 계정, 반환된 일치 확률(%) 로그 조회. 원시 코사인 점수와 AS-Norm 정규화 점수를 병기하여 정규화 효과 추적.

## 4. 인증 품질 모니터링 및 캘리브레이션 (Phase B 연동)
*   **점수 분포 시각화:** 동일인(Genuine) / 타인(Impostor) 시도별 점수 히스토그램 오버레이 — 분포 겹침 정도로 시스템 분별력을 직관 확인.
*   **EER / minDCF 추적:** 오수락률(FAR)·오거부률(FRR) 곡선과 교차점(EER)을 기간별로 차트화. 성능 저하(드리프트) 조기 감지.
*   **임계값 캘리브레이션 UI:** 관리자가 FAR/FRR 트레이드오프를 확인하며 판정 임계값(Threshold)을 조정·배포. 조정 이력은 오딧 트레일에 기록.
*   **코호트 관리:** AS-Norm용 임포스터 코호트 임베딩 규모·갱신 일자 확인 및 재구축 트리거.

## 5. 전처리·보안 품질 로그 (Phase C/D 연동)
*   **전처리 품질 지표:** 요청별 VAD 통과 유효 발화 길이, (분리 적용 시) 검출 화자 수 및 분리 품질 지표(SI-SNRi) 로그. 유효 발화 부족으로 반려된 요청 비율 모니터링.
*   **스푸핑 탐지 로그:** AASIST 계열 모듈이 반환한 `spoof_score` 및 차단 이력 조회 — 딥페이크 공격 시도 패턴(IP·계정·시간대) 분석 뷰.
*   **경보 (Alerting):** 스푸핑 차단 급증, EER 급등, 응답 지연 임계 초과 시 관리자 알림.
