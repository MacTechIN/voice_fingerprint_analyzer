# 05_Functional_Requirements.md
# 기능 요구사항 정의서 (Functional Requirements)

## 1. 프로토타입 핵심 요구사항 (Phase A)

| 요구사항 ID | 기능 분류 | 기능 명칭 | 상세 설명 | 우선순위 |
| :--- | :--- | :--- | :--- | :---: |
| **FR-01** | 클라이언트 | 음성 수집 및 UI | 사용자가 기기에서 음성을 녹음하고, 실시간 파형 피드백을 받는다. (16kHz/16-bit/Mono, 최소 3초 발화 강제) | High |
| **FR-02** | 클라이언트 | 파일 임시 저장 및 전송 | 녹음 완료 즉시 오디오 데이터를 서버 API로 Multipart 전송 후 로컬에서 삭제한다. | High |
| **FR-03** | 서버 | 성문 특징 추출 | 서버는 전송받은 오디오에서 무음 구간을 제거(VAD)하고 딥러닝 모델에 통과시켜 벡터 지문을 생성한다. VAD 통과 유효 발화가 기준 미달이면 사유 코드와 함께 반려한다. | High |
| **FR-04** | 서버 | 신규 등록 처리 | 생성된 벡터를 DB에 신규 사용자로 암호화하여 저장한다. (모델명·버전·차원 메타데이터 병기) | High |
| **FR-05** | 서버 | 유사도 분석 (1:1) | 검증 요청 시, 입력 벡터와 DB 내 타겟 사용자 벡터 간의 코사인 유사도를 서버에서 계산한다. | High |
| **FR-06** | 서버 | 결과 반환 | 유사도 점수를 0~100% 형식으로 변환하여 클라이언트 앱으로 반환(JSON)한다. (Threshold 초과 시 True 반환) | High |
| **FR-07** | 클라이언트 | 결과 시각화 | 서버로부터 받은 일치 확률을 사용자 친화적인 그래픽(애니메이션)으로 표시한다. | Mid |

## 2. 품질 강화 요구사항 (Phase B)

| 요구사항 ID | 기능 분류 | 기능 명칭 | 상세 설명 | 우선순위 |
| :--- | :--- | :--- | :--- | :---: |
| **FR-08** | 서버 | 음성 향상 전처리 | 임베딩 추출 전 DeepFilterNet 기반 소음 억제를 적용하여 배경 소음의 임베딩 오염을 차단한다. | High |
| **FR-09** | 서버 | AS-Norm 점수 정규화 | 임포스터 코호트에서 상위 K개 유사 발화를 적응 선택하여 원시 코사인 점수를 대칭 정규화($S_{AS\text{-}Norm}$)한 뒤 판정한다. 원시 점수와 정규화 점수를 모두 로그에 기록한다. | High |
| **FR-10** | 서버 | 코호트 DB 관리 | AS-Norm용 임포스터 임베딩 코호트를 사용자 DB와 격리된 테이블로 구축·갱신한다. | High |
| **FR-11** | 웹 관리자 | 임계값 캘리브레이션 | 관리자가 FAR/FRR 곡선과 EER·minDCF 지표를 확인하며 판정 임계값을 조정·배포할 수 있다. | Mid |
| **FR-12** | 웹 관리자 | 품질 지표 대시보드 | Genuine/Impostor 점수 분포, EER 추이, 반려율(발화 부족 등)을 시각화한다. | Mid |

## 3. 다중 화자 대응 요구사항 (Phase C)

| 요구사항 ID | 기능 분류 | 기능 명칭 | 상세 설명 | 우선순위 |
| :--- | :--- | :--- | :--- | :---: |
| **FR-13** | 서버 | 음성 분리 | 다중 화자가 겹친 오디오에서 개별 화자 발화를 분리(SepFormer 계열 또는 Mamba-TasNet)하여 각각 임베딩 추출이 가능하도록 한다. | Mid |
| **FR-14** | 서버 | 타겟 화자 추출 (TSE) | 검증 요청 시 등록 임베딩을 조건으로 타겟 화자 발화만 추출하여 순열 문제를 회피하고 비타겟 음성을 억압한다. | Mid |
| **FR-15** | 서버 | 분리 왜곡 보정 | 분리 아티팩트로 인한 임베딩 왜곡에 대응하기 위해, 아티팩트 증강 데이터로 파인튜닝된 임베딩 모델(ERes2NetV2 기반)을 사용한다. | Mid |

## 4. 보안 요구사항 (Phase D)

| 요구사항 ID | 기능 분류 | 기능 명칭 | 상세 설명 | 우선순위 |
| :--- | :--- | :--- | :--- | :---: |
| **FR-16** | 서버 | 딥페이크 탐지 | 검증 파이프라인 초입에 AASIST 계열 Anti-Spoofing 모듈을 배치하여 TTS/보이스 컨버전 합성 음성을 차단하고 `spoof_score`를 기록한다. | High |
| **FR-17** | 웹 관리자 | 스푸핑 감사 로그 | 스푸핑 차단 이력(IP·계정·시간대·점수)을 조회하고, 차단 급증 시 경보를 발생시킨다. | Mid |
| **FR-18** | 클라이언트 | 스푸핑 차단 UX | 합성 음성 판정 시 일치율 대신 "실제 음성 확인 실패" 안내를 표시한다 (탐지 상세는 비노출). | Mid |
